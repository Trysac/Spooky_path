## Made for this project

| Asset | Where | How it was made |

| Levels | `Assets/Scripts/Core/Levels.cs` | Text maps, built into scenes at run time by `LevelView.cs` |
| Materials, lava texture, particle texture, explorer animator, scene, app icon, UI panel settings | `Assets/Art`, `Assets/Scenes`, `Assets/UI` | Generated by `Assets/Editor/ProjectBuilder.cs` |

| HUD and menus | `Assets/UI` | Written for this project (UXML and USS) |

## Removed third-party content

Earlier versions of this repository (before the `fix/asset-licensing` changes) contained
Unity Asset Store packages (Hovl Studio Magic effects pack, Magic VFX - Ice (FREE), Unity
Technologies effect examples, Fantasy Wooden GUI Free, GUI Parts, the Code Assist editor
plugin), a stylized lava material, display fonts, music, sound effects, voice clips, an intro
video and images whose origin or licence was not recorded, including institutional logos.
They were removed and replaced with the generated content above.
